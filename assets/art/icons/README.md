# Prop / doll icons (AB-24) + hearts (AB-25)

Q-pixel transparent RGBA PNGs for inventory / vista props. Warm cream–brown–blush palette matching couple packs.

## Style

- Logical grid: **64×64** → display export **256×256** (4× nearest)
- Dark brown outlines; hot-pink chroma-key → BOX fit → 16-color median-cut → nearest upscale
