# Greeting card art

Q-pixel covers + edge icons for the foldable e-cards (`cards.html`).

| Folder | Cover theme | Edge icons |
|--------|-------------|------------|
| `bigcity/` | Christmas wreath | perfume, lipstick, bag, necklace, ring |
| `boutique/` | Cinnamoroll | cinnamoroll, labubu, bunny, bear, egg |
| `yakiniku/` | Aromatic grill | skewer, meat, tongs |
| `photos/` | Inner-left placeholders | swapped from `pixel/01,03,05` — replace anytime |

Paper colors / borders are CSS themes in `cards.css` (`.card-theme--*`).
